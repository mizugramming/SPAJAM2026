# いろみがき

大会のテーマは「色」。会場で初めて遊ぶ人が、自分の声でやすりを選び、スマホをやすりに見立てて素材を磨く。サビの下から色が現れることと、表面が滑らかになるにつれて手触りが変わることが主役。

## 遊び方と完成条件

| 場面 | プレイヤーの操作 | ゲームの反応 |
|---|---|---|
| タイトル | 起動時に「はじめる」をタップ | 素材選択へ。「もう一度遊ぶ」の後はタイトルを挟まない |
| 素材選択 | メダルか漢をタップ | 選んだ素材の初期値から1回目を開始 |
| 採音 | 机に端末を置き、「声を取る」を押して一定の声を約1.2秒出す | 端末内でHzを推定し、同時に静止時の加速度を測る。無音・不安定・権限拒否は入力をやり直せる。進捗とラウンドは保持 |
| やすり決定 | やすりを確認し、スマホを持って構え、研磨を開始 | ここから10秒。採音・準備時間は含めない |
| 研磨 | 机と平行にスマホを押し引きする | 押し始めに光が出て、素材の上を滑らせる間に振動する。折り返しで減速すると振動が引き、1往復で素材が削れる。手を止めたり上に離したりすると接触が終わる |
| 2・3回目 | 同じ素材で再び採音・研磨 | やすりを選び直し、直前までの素材値から続ける |
| 仕上がり | 確定した表面・段階名・合計往復数を見る。「もう一度遊ぶ」 | 素材選びへ戻る。新しいプレイは初期値から |

目標がなくても、0往復を含め3回で必ず仕上がりに着く。メダルはサビた銅→銅→銀→金、漢はこびりついた汚れ→現れた輪郭→光沢を帯びた字面へ変わる。判定と見た目は実際に削った量で決まる。目標・磨きすぎ・点数は企画担当が決めた段階で追加できる。[設定と採点の差し替え](project_structure.md)

## デザインと部品

- 黒に近い作業台（#0F0C0C）に素材を大きく置く。本文は白墨色（#F4F1E8）。差し色は赤（#C8262E：主ボタン・ロゴのマーク）と、枠線の暗い赤（#4F2323）、炎の橙（#FF9A4D：残り時間・時間バー・矢印）。背景と文字を抑え、金・銀など素材の色が最も目立つようにする。色と併せて段階名・往復数・秒を表示する。Androidの起動時背景（`styles.xml`）は旧色 #121717 のまま。
- 日本語ゴシックのNoto Sans JPを同梱。ゲーム画面の部品はSafeArea内の幅・高さに対する割合で配置し、文言は各枠に収める。開発用Chromeでは「配置を編集」で部品を動かし、「ファイル用にコピー」で得た配置表を `lib/ui/workshop_layout.dart` に保存できる。
- 選択カードは磨ける素材の見本を表示し、採音以降の作業面はそのプレイの実値を表示。Canvasで表面・汚れ・反射光を重ね、往復で汚れが散る。静止時も汚れの位置を固定する。動きを減らす端末設定では短い演出を抑える。
- 共通の配色・書体は `lib/ui/workshop_theme.dart`、主ボタン・操作文言・カード・作業面枠は `lib/ui/workshop.dart`、素材の汚れと反射の描画は `lib/ui/surface_art.dart` に置く。

## 初期版の判断

2026-11-21の依頼で示された導線・2題材・3ラウンドを初期版の範囲とした。仮称を「いろみがき」とし、Android実機1台でオフライン動作する。端末内の音声バッファは判定後に破棄し、プレイ状態・計測結果はメモリにだけ持つ。アプリを閉じると最初から。バックグラウンドでは研磨・時計を休止し、ゲームに戻ると残りから続ける。

声の高さが会場で安定しなければ、採音画面で音量へ切り替える。往復検出が実機で成立しないと分かった場合に、企画担当と指でこする代替を検討する。PCの疑似入力は開発用。大会終了までの時間、追加条件、Hzや加速度の最終閾値、最終採点は未確定。現在の閾値と実機試験は[端末担当の手順](device_trials.md)に記載した。
