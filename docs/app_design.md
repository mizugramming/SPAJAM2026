# 磨くでヤンス！

大会のテーマは「色」。会場で初めて遊ぶ人が、自分の声でやすりを選び、スマホをやすりに見立てて素材を磨く。サビの下から色が現れることと、表面が滑らかになるにつれて手触りが変わることが主役。

## 遊び方と完成条件

| 場面 | プレイヤーの操作 | ゲームの反応 |
|---|---|---|
| タイトル | 題字「磨くでヤンス！」とキャラクターを見て「はじめる」をタップ | 素材選択へ。「もう一度遊ぶ」の後はタイトルを挟まない |
| 素材選択 | 自分の声に合う「声が低い人」「声が高い人」を選ぶ。左右にスワイプするか隣の素材をタップして、中央の素材を切り替える。「これを磨く」で確定。「‹ 戻る」でタイトルへ | 最初は灰色の「漢」を中央に表示する。漢を確定すると上へ薄れながら抜け、採音画面の上から作業位置へ降りる。メダルを確定すると、緑青のついた銅メダルが回転しながら上へ消え、採音画面の上から作業面に降りてくる。各素材の初期値から1回目を始める。スワイプだけでは進まない |
| 採音 | 素材に応じた「一回目／全二回」「一回目／全三回」などのカットインが消えたら、マイクを押して一定の声を約1.2秒出す。1回目は「戻る」で選んだ素材に戻れる | 画面左上に回数、右上に素材名を表示する。選んだ声域で粗目・中目・細目を決める。声域は再挑戦にも引き継ぐ。端末内でHzを推定し、同時に静止時の加速度を測る。安定したHzを取れなければ同じ回で採り直す。権限拒否時もマイクの許可後に再試行できる |
| やすり決定 | 中央の測定値とやすりの目を見て、スマホを構える | マイクが上へ抜け、紙が画面下部に着地する。0.65秒後、端末の計測準備が整うと「磨け！」が横切り、その瞬間から10秒磨ける |
| 研磨 | 机と平行にスマホを押し引きする | 押し始めに削り粉が舞い、素材の上を滑らせる間に振動する。折り返しで減速すると振動が引き、1往復で素材が削れる。手を止めたり上に離したりすると接触が終わる |
| 次の回 | 同じ素材で再び採音・研磨 | 前の回が終わったときの素材値から続ける。メダルは全2回、漢は最大3回 |
| 仕上がり | 表面の色・ツヤと仕上がりの名前を見る。「もう一度遊ぶ」か「タイトルへ」 | 素材選びかタイトルへ戻る。新しいプレイは初期値から。端末の戻る操作で終わったプレイは出ない |

研磨は1回10秒。メダルは研磨中、サビた銅→銅→銀→金と変化する。粗目で金になる基準は全端末で50往復。漢にも同じ基準でやすりごとの削り量を適用する。金の仕上げには細目が向き、最終ラウンドではすべてのやすりで金ピカまで磨ける。

金から金ピカまでは、往復で研磨率が50%から95%に近づくほど、つや消しの地金に光沢が重なる。1回目の終了時には研磨率を50〜90%に収めて金にする。2回目の残り1秒で研磨率が95%未満なら95%まで引き上げる。0往復でも結果画面ですぐにスクラッチを始められる。仕上げたメダルの上部をなぞると、引いた方向に箔が細い筋になって剥がれ、削った部分から「最優秀賞」が現れる。漢はくすんだ銀の立体文字に磨いた銀の絵を重ね、実際に磨いた分だけ光沢を出す。

漢の初期残量は100。研磨量80〜90（両端を含む）に達すると「そろそろ…」が出る。80未満で3回を終えると、結果に元の灰色の「漢」と磨き不足のキャラクターが出る。90を超えた往復で時計と振動を止め、何回目でも即座に「漢割り」へ移る。割れる漢の色は、その時点までに選んだやすりの合計点で決まる。2〜5漢はひびが開いて左右の破片が離れ、1漢は既存の5コマで割れる。

範囲内で3回を終えると、3枚のやすりの合計点（粗目3・中目2・細目1）に応じた段位と称号が出る。段位の「漢」が回転して現れ、続いて動くキャラクター、最後に称号札と、その称号に応じたひとことが現れる。動きを減らす設定では、段位・静止キャラクター・称号とひとことをすぐに表示する。

| 合計点 | 段位 | 称号 |
|---|---|---|
| 3 | 5漢 | 韓国系 |
| 4・5 | 4漢 | 塩顔 |
| 6 | 3漢 | ムキムキ |
| 7・8 | 2漢 | 醤油顔 |
| 9 | 1漢 | 九州男児 |

## デザインと部品

舞台は昭和の商店街にある「磨かれ屋」。開店前ののれん越しに、磨いてもらうのを待つヤンスと目が合う。店名は柿朱ののれんに染め抜く。その下にゲームの題字を一行で置き、ヤンスの目と表情を画面中央に大きく見せる。奥から順に、棚と柱、ヤンス、接客カウンター、手元の道具を重ねる。天板の奥縁は短パンの帯のすぐ下を横切り、顔とお腹は見える。素材を選ぶ画面からは同じカウンターの天面を少し広く見せる。

小物の縮尺はヤンスの肩幅と手を基準にする。右の柱には本人が羽織れる大きさのデニムジャケットを掛ける。奥の左棚には上段に本を2冊、下段に片手用のダンベルを置く。手前の天板の左に藍の布を敷き、ワックスの容器と外した蓋を並べる。右には蓋を含めたワックスより少し長い刷毛を寝かせる。画面ごとに天板の位置が変わっても、この比率と接地を保つ。

開発版Chromeの「配置を編集」で、のれん・小物・人物・カウンターの位置と大きさを画面ごとに調整できる。「ファイル用にコピー」で配置表を書き出せる。

設定は藍の札から開く。途中で素材選びに戻るときは、生成りの紙に「続ける」と「素材選びに戻る」の札を並べる。[タイトル・素材選択・採音の実画面](images/migakareya-app.webp)

- 黒に近い作業台（#0F0C0C）に素材を大きく置く。本文は白墨色（#F4F1E8）。研磨中は炎の橙（#FF9A4D）で残り秒数と時間バーを示し、結果画面には仕上がりの段階名を表示する。
- 「はじめる」「これを磨く」「もう一度遊ぶ」はのれんに合わせた柿朱（#99482F）の木札、設定・戻る操作は藍（#414F59）の木札を使う。隅を小さく落とし、木目は縁に寄せて文字を読みやすくする。声域と疑似音声は生成りの札から選び、選んだ札を藍とチェックで示す。
- 筆文字のYuji Syukuと、日本語ゴシックのNoto Sans JPを同梱。主ボタンの文字は基準34論理ピクセルで、狭い枠では一行に収める。ゲーム画面の部品はSafeArea内の幅・高さに対する割合で配置する。素材名・やすりの目・残り時間・仕上がり名は一行で読み切れるようにし、長い案内は文節で折り返す。
- 回転式の素材選択ではメダルを研磨前のサビた状態で表示し、採音以降の作業面はそのプレイの実値を表示。Canvasで表面・汚れ・反射光を重ね、往復で汚れが散る。静止時も汚れの位置を固定する。動きを減らす端末設定では短い演出を抑える。
- 準備・研磨中は画面上部の暗い作業台にメダルや「漢」を大きく置く。素材の色・ツヤで研磨の進み具合を示し、両素材とも押し引きの間は粉が舞い、往復が確定すると破片が散る。段階名と研磨率は作業面の読み上げでも確認できる。採音ボタンが上へ抜けた後、横長の紙が素材の手前を通り、画面下約3割に着地する。マイクの移動・中央での読み取り・紙の着地を合わせて1.8秒。動きを減らす設定では紙を定位置にすぐ表示し、同じ0.65秒を置いて「磨け！」を静止表示する。
- 紙の裏に「190 Hz」のように声の高さを繰り返し印字する。低い声の赤土色から、190 Hzの砂色を経て、高い声の青灰色へ連続的に変わる。
- ゆっくり滑らせるほど長めに、速く滑らせるほど短く刻んで振動する。弱い動きでも押しと引きがそろうと1往復分だけ素材が削れる。やすりの粗さと素材の研磨率を手触りに反映する。
- 採音は朱色の丸印に生成りのマイクを描き、押すとわずかに沈む。採音中は印を薄くして二重入力を防ぎ、読み取りに入ると同じ印が紙へ移動する。丸い形と押し込みは「いろみがきの音声ボタン」を参考にした。[SPAJAM UI Arsenal](https://spajam-ui-arsenal.ktbys0315.chatgpt.site/)
- 共通の配色・書体は `lib/ui/workshop_theme.dart`、主ボタン・操作文言・カード・作業面枠は `lib/ui/workshop.dart`、素材の汚れと反射の描画は `lib/ui/surface_art.dart` に置く。

## 初期版の判断

2026-11-21の依頼で示された導線・2題材・3ラウンドを初期版の範囲とした。Android実機1台でオフライン動作する。端末内の音声バッファは判定後に破棄し、プレイ状態・計測結果はメモリにだけ持つ。アプリを閉じるとプレイは最初から。バックグラウンドでは研磨・時計を休止し、ゲームに戻ると残りから続ける。

高さが安定しなかったときはマイクを押して同じ高さで声を出し直す。往復検出が実機で成立しないと分かった場合に、企画担当と指でこする代替を検討する。PCの疑似入力は開発用。大会終了までの時間、追加条件、Hzや加速度の最終閾値、最終採点は未確定。現在の閾値と実機試験は[端末担当の手順](device_trials.md)に記載した。

## 発表用の調整（2026-11-22）

- タイトルは「磨くで」と「ヤンス！」を同じ大きさで横一列に並べる。
- 素材選択の見出しは「メダルを磨く」「「漢」を磨く」。
- メダルは2回で終わる（素材ごとの回数 `rounds`）。1回目の終わりは、どれだけ削っても輝く前の金（研磨50〜90%、`afterEarlierRounds`）。2回目は残り1秒で必ず金ピカ（研磨95%以上、`finishAtLeast`）になり、結果画面ですぐ箔を削って刻印を出せる。漢は3回のまま。
- 漢磨きの結果画面は、称号と「漢」の間に称号のひとことを出す（九州男児：ガサツなのに実は優しいオトコ♡／醤油顔：あなたの力強さと柔らかさにトリコだわ♡／ムキムキ：その筋肉で私を運んでー♡／塩顔：その透明感に吸い込まれちゃう♡／韓国系：あなたの甘い笑顔にキュン♡、配置表の `comment`）。
- 漢磨きの結果はゲーム側の目標研磨（`targetFinish`）で決まる。磨き不足のときは段位によらず `character-under.webp`（動画から作った動くWebP）を出す。目標どおりなら段位・人物・称号・ひとこと、削りすぎなら漢が割れる。
