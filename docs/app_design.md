# 磨くでヤンス！

大会のテーマは「色」。会場で初めて遊ぶ人が、自分の声でやすりを選び、スマホをやすりに見立てて素材を磨く。サビの下から色が現れることと、表面が滑らかになるにつれて手触りが変わることが主役。

## 遊び方と完成条件

| 場面 | プレイヤーの操作 | ゲームの反応 |
|---|---|---|
| タイトル | 題字「磨くでヤンス！」とキャラクターを見て「はじめる」をタップ | 素材選択へ。「もう一度遊ぶ」の後はタイトルを挟まない |
| 素材選択 | 自分の声に合う「男性用」「女性用」を選ぶ。左右にスワイプするか隣の素材をタップして、中央の素材を切り替える。「これを磨く」で確定。「‹ 戻る」でタイトルへ | メダルを確定すると、緑青のついた銅メダルが回転しながら上へ消え、採音画面の上から作業面に降りてくる。各素材の初期値から1回目を始める。スワイプだけでは進まない |
| 採音 | 各回の「一回目／全三回」などのカットインが消えたら、マイクを押して一定の声を約1.2秒出す。1回目は「戻る」で選んだ素材に戻れる | 画面左上に回数、右上に素材名を表示する。選んだ声域で粗目・中目・細目を決める。声域は再挑戦にも引き継ぐ。端末内でHzを推定し、同時に静止時の加速度を測る。安定したHzが得られないときは音量で分類する。無音・権限拒否は採り直せる |
| やすり決定 | 中央の測定値とやすりの目を見て、スマホを構える | マイクが上へ抜け、紙が画面下部に着地する。0.65秒後、端末の計測準備が整うと「磨け！」が横切り、その瞬間から10秒磨ける |
| 研磨 | 机と平行にスマホを押し引きする | 押し始めに削り粉が舞い、素材の上を滑らせる間に振動する。折り返しで減速すると振動が引き、1往復で素材が削れる。手を止めたり上に離したりすると接触が終わる |
| 2・3回目 | 同じ素材で再び採音・研磨 | やすりを選び直し、直前までの素材値から続ける |
| 仕上がり | 表面の色・ツヤと仕上がりの名前を見る。「もう一度遊ぶ」か「タイトルへ」 | 素材選びかタイトルへ戻る。新しいプレイは初期値から。端末の戻る操作で終わったプレイは出ない |

同じ素材を10秒ずつ3回磨く。メダルは研磨中、サビた銅→銅→銀→金と変化する。粗目で金まで磨く基準は標準22往復。素材選択の「設定」で5〜60往復に変えると、漢を含む各素材の1往復あたりの削り量が同じ比率で変わる。金の仕上げには細目が向き、最終ラウンドではすべてのやすりで金ピカまで磨ける。

金から金ピカまでは、往復で研磨率が50%から95%に近づくほど、つや消しの地金に光沢が重なる。3回目が終わると、メダルは最後に磨いた状態で結果画面に移る。残りは時間制限なく指で磨ける。0往復で終わった人も同じ手順で仕上げられ、すでに95%に届いた人はそのままスクラッチを始められる。仕上げたメダルの上部をなぞると、引いた方向に箔が細い筋になって剥がれ、削った部分から「最優秀賞」が現れる。漢はくすんだ銀の立体文字に磨いた銀の絵を重ね、実際に磨いた分だけ光沢を出す。

漢磨きの結果画面では、3回のやすりの目を点数（粗目3・中目2・細目1）にして合計し（3〜9点）、段位とキャラクターを出す。段位ごとの色の「漢」の絵を表示し、読み上げでは「3漢」のように段位も伝える。配置表の `rank` で位置と大きさを変えられる。成功の範囲は別の担当が決める予定で、`lib/ui/workshop.dart` の `kanjiSucceeded` に仮の決まり（最後の段階まで磨けたら成功）を置いている。

| 合計 | 段位 | 成功 | 失敗 |
|---|---|---|---|
| 3 | 5漢 | character-05 | overpolished-05 |
| 4・5 | 4漢 | character-04 | overpolished-04 |
| 6 | 3漢 | gyansu | overpolished-03 |
| 7・8 | 2漢 | character-02 | overpolished-02 |
| 9 | 1漢 | 九州男児（kyushu-danji） | overpolished-01 |

## デザインと部品

昭和の町角にある小さな磨き屋は、ヤンスが身支度をする場所でもある。右の木柱には参考画の右端の人物が着ている藍色のジャケットと磨き刷毛を掛ける。木の台には読みかけの本と鉄のダンベルを置き、開いたヘアワックスを藍の布に載せる。小物は人物と同じ太い墨線と少ない色面で描く。

波柄ののれんの下は、題字と研磨する素材が見えるよう中央を空ける。タイトルのヤンスは輪郭で切り抜き、足の間にも天板が見えるように立たせる。赤い開始ボタンには「はじめる」を中央に置く。開発版Chromeの「配置を編集」で、小物の位置と大きさを画面ごとに調整できる。「ファイル用にコピー」で配置表を書き出せる。

- 黒に近い作業台（#0F0C0C）に素材を大きく置く。本文は白墨色（#F4F1E8）。差し色は赤（#C8262E：主ボタン）と、枠線の暗い赤（#4F2323）、炎の橙（#FF9A4D：残り時間・時間バー・矢印）。背景と文字を抑え、金・銀など素材の色が最も目立つようにする。研磨中は残り秒数と時間バー、結果画面では仕上がりの段階名を表示する。Androidの起動時背景（`styles.xml`）は旧色 #121717 のまま。
- 筆文字のYuji Syukuと、日本語ゴシックのNoto Sans JPを同梱。「はじめる」「これを磨く」「もう一度遊ぶ」は共通の赤い主ボタンを使う。文字は基準34論理ピクセルで、狭い枠では一行に収める。かすれ模様は白い文字の背面に描く。ゲーム画面の部品はSafeArea内の幅・高さに対する割合で配置する。素材名・やすりの目・残り時間・仕上がり名は一行で読み切れるようにし、長い案内は文節で折り返す。開発用Chromeでは「配置を編集」で部品を動かし、「ファイル用にコピー」で得た配置表を `lib/ui/workshop_layout.dart` に保存できる。
- 回転式の素材選択ではメダルを研磨前のサビた状態で表示し、採音以降の作業面はそのプレイの実値を表示。Canvasで表面・汚れ・反射光を重ね、往復で汚れが散る。静止時も汚れの位置を固定する。動きを減らす端末設定では短い演出を抑える。
- 準備・研磨中は画面上部の暗い作業台にメダルや「漢」を大きく置く。素材の色・ツヤで研磨の進み具合を示し、両素材とも押し引きの間は粉が舞い、往復が確定すると破片が散る。段階名と研磨率は作業面の読み上げでも確認できる。採音ボタンが上へ抜けた後、横長の紙が素材の手前を通り、画面下約3割に着地する。マイクの移動・中央での読み取り・紙の着地を合わせて1.8秒。動きを減らす設定では紙を定位置にすぐ表示し、同じ0.65秒を置いて「磨け！」を静止表示する。
- 紙の裏に「190 Hz」のように声の高さを繰り返し印字する。低い声の赤土色から、190 Hzの砂色を経て、高い声の青灰色へ連続的に変わる。音量モードで高さが取れなければ砂色の紙に実測音量の割合を印字する。
- ゆっくり滑らせるほど長めに、速く滑らせるほど短く刻んで振動する。弱い動きでも押しと引きがそろうと1往復分だけ素材が削れる。やすりの粗さと素材の研磨率を手触りに反映する。
- 採音画面の丸いマイクボタンは、[SPAJAM UI Arsenal](https://spajam-ui-arsenal.ktbys0315.chatgpt.site/) の見本「いろみがきの音声ボタン」（2026-11-22確認）から、朱色の丸い形・縁・照り返しと厚みの影・押し込み・マイク記号を取り入れた。見本のにじみ画像は利用条件が未確認のため使わず、かすれ模様で代える。見本の再生中の停止表示は、採音を途中で止められないため使わず、採音中は薄くして押せなくする。
- 共通の配色・書体は `lib/ui/workshop_theme.dart`、主ボタン・操作文言・カード・作業面枠は `lib/ui/workshop.dart`、素材の汚れと反射の描画は `lib/ui/surface_art.dart` に置く。

## 初期版の判断

2026-11-21の依頼で示された導線・2題材・3ラウンドを初期版の範囲とした。Android実機1台でオフライン動作する。端末内の音声バッファは判定後に破棄し、プレイ状態・計測結果はメモリにだけ持つ。アプリを閉じるとプレイは最初から。選んだ研磨回数だけは端末に保存する。バックグラウンドでは研磨・時計を休止し、ゲームに戻ると残りから続ける。

声の高さが安定しない場合は音量で自動判定し、紙にも測定した音量を印字する。往復検出が実機で成立しないと分かった場合に、企画担当と指でこする代替を検討する。PCの疑似入力は開発用。大会終了までの時間、追加条件、Hzや加速度の最終閾値、最終採点は未確定。現在の閾値と実機試験は[端末担当の手順](device_trials.md)に記載した。
