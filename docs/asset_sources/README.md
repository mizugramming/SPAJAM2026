# 担当別の素材出典

担当ごとのMarkdownへ追記します。同じ共通一覧を全員で編集しないための分割です。ファイル名と担当は[画像の追加手順](../adding_assets.md)を参照してください。

以下を素材ごとに記載します。外部素材は実際の配布元と利用条件を確認し、ライセンス文やクレジットが必要ならその配置先も記録します。

```text
## 素材名
- アプリ内パス：assets/担当機能/画像名.png
- 用途：表示する画面・場面
- 入手方法：自作 / 外部素材 / AI生成
- 出典：作者・配布元URL、または生成ツール・生成日
- 利用条件：ライセンス名、必要なクレジットとその配置先
- 加工内容：リサイズ・トリミング・色変更など
- AI生成の場合：参考素材の出典とプロンプト（秘密情報を含めない）
```

既存の共通素材は[素材と生成記録](../assets.md)にあります。この運用の追加は、過去のすべての素材について出典を確認済みとするものではありません。
