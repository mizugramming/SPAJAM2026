# Codexへの開始指示

`APP_DESIGN.md` を読み、既存リポジトリと適用される `AGENTS.md` を確認してから実装してください。

## 今回の優先事項

1. ラベルのない「はだ缶」から開始する。
2. ニックネーム・趣味・ひとことの入力欄を初めから開き、入力中にラベルへ即時反映する。
3. 手書き13ページを基準にしたホームを作る。ただしメンバー表示・メンバーボタン・下部タブは入れない。
4. 同チームは協力、別チームは対戦。ゲーム本体は未決定なので空の差し込み領域にする。ゲーム中の缶と親分は右下へ縮小移動する。
5. 勝利の踊り、敗北の「ショBONE」、子分の「よろしく(ツ)ナ」、缶への吸い込み、協力での復活を実装する。
6. 子分登場の場面に「ホームに戻る」を設ける。
7. 普通3・骨1で最終戦力を計算し、主催者設定の期限後に綱引きへ進める。順位は今回のルームだけを対象にする。
8. 一台用デモを用意し、正式ゲームなしでも結果を再現して画面・報酬・進行を確認できるようにする。

## 判断の扱い

- 設計書の「確定 C」と「暫定 P」「未決定 U」を混同しない。
- 暫定案を採用したときは、採用したPのIDを記録する。ユーザーが個別承認したと書き換えない。
- ゲームの内容、MVPの判定、協力報酬の細則などを勝手に確定しない。
- 不足箇所があっても進められる部分は実装する。重大な判断だけ未決定事項として提示する。
- `references/ui/` の画像は修正前の参考。メンバー、タブ、具体的なミニゲーム、期間ランキング、リプレイをコピーしない。
- 結果選択などの検証用操作を通常モードに出さない。

計画だけで終わらず、実行可能な範囲の実装・テストまで進めてください。
完了時は、実装済み、採用した暫定案、未搭載、実施テスト、実機・通信の未検証事項を分けて報告してください。
