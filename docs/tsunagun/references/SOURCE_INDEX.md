## 根拠の区別

- 手書きラフの配置・絵：PDFの該当ページを根拠とする。
- ラフの意味、削除要素、固定セリフ、ゲームを空ける指示：その後のユーザーの会話を根拠とする。
- 具体的な技術構造、協力報酬の細則、必須項目、MVP基準等：本書で明示した暫定案。原図から読み取れた決定ではない。

アプリの最新リポジトリや外部ドキュメントの調査は、本ファイル作成の範囲には含めていません。
