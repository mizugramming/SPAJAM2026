## 得点の内訳

「子分は3、骨は1のちから」という独立した説明文を削除し、綱引きの決着後と個人順位で実数の内訳を示します。子分は普通の子分、骨は骨の子分です。

- 子分：匹数 × 3pt と小計。
- 骨：匹数 × 1pt と小計。
- 合計：両方の小計を足したちから。

得点は確定した集計から表示します。観客席の子分・骨や親分のイラストを得点へ数えません。復活時の増分は骨1ptから普通3ptへの差分の＋2で、新規の普通子分は＋3です。
