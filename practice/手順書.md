# 🔰 はじめてのGit練習

ここは練習用のフォルダです。以下の手順で、自分のファイルを作ってPull Requestを出してみましょう！

## 0. 【初回のみ】手元にコードを持ってくる
まだ自分のパソコンにこのアプリのフォルダがない人は、最初に1回だけダウンロード（クローン）します。
`git clone https://github.com/mizugramming/SPAJAM2026.git`
`cd SPAJAM2026` （←ダウンロードしたフォルダの中に移動します）

--- ここから下は、作業をするたびに毎回やります！ ---

## 1. 【毎回】手元のコードを最新にする（⚠️超重要！）
作業を始める前に、必ずクラウド上の最新の状態を手元に上書き（同期）します。これをやらないとエラーになります！
`git switch main`
`git pull origin main`

## 2. 自分の作業用ブランチを作る
直接mainをいじらないように、自分の分身となるブランチを作ります。(ここに関してはいきなり本番ではなく、一旦下書きを書くような感じです)
`git switch -c feature/practice-自分の名前`

## 3. ファイルを作って保存する
この `practice` フォルダの中に、自分の名前のファイル（例： `taro.md`）を作って、好きな食べ物など(なんでもいいです)を書いて保存します。

## 4. 変更をGitHubへ送る
以下のコマンドを順番に打って、変更内容をクラウドへ送ります。
`git add .`
`git commit -m "練習"`
`git push origin feature/practice-自分の名前`
↑ここには何を変更したかとかを書いてもらえるとわかりやすいです。

## 5. GitHubでPull Requestを作る
GitHubの画面を開いて「Pull Request」を作成し、自分で「Merge」ボタンを押して合流させます！
