# 🔰 はじめてのGit練習

ここは練習用のフォルダです。以下の手順で、自分のファイルを作ってPull Requestを出してみましょう！

## 0. 【初回のみ】手元にコードを持ってくる
まだ自分のパソコンにこのアプリのフォルダがない人は、最初に1回だけダウンロード（クローン）します。

`git clone https://github.com/mizugramming/SPAJAM2026.git`

`cd SPAJAM2026` （←ダウンロードしたフォルダの中に移動します: 'cd' ="change directory"）

--- ここから下は、作業をするたびに毎回やります！ ---

## 1. 【毎回】手元のコードを最新にする（⚠️超重要！）
作業を始める前に、GitHub上の最新の変更を、自分のパソコンにも反映します。これをやらないとエラーになります！

`git switch main`

`git pull origin main`

'git status'

## 2. 自分の作業用ブランチを作る
直接mainをいじらないように、自分専用のブランチ(作業場所)を作ります。(ここに関してはいきなり本番ではなく、一旦下書きを書くような感じです)

`git switch -c feature/practice-自分の名前`

例：
`git switch -c feature/practice-matumoto`

### 2-1. 次回同じ作業を再開するとき
すでにブランチを作っている場合は、新しく作らず、そのブランチに移動します。

`git switch feature/practice-自分の名前`

例：

`git switch feature/practice-matumoto`

今いるブランチが分からなくなったら、以下で確認できます。

git branch

* が付いているものが、現在いるブランチです。

### 2-2. 自分のブランチ(作業場所)に更新した内容を持ってくる

`git merge main`

これでmainブランチの内容を自分のブランチに反映することが出来ます。

## 3. ファイルを作って保存する
この `practice` フォルダの中に、自分の名前のファイル（例： `taro.md`）を作ります。

例：
`practice/matumoto.md`

好きな食べ物、趣味、自己紹介など、内容は何でもOKです。

## 4. 変更をGitHubへ送る
まず変更内容を確認します。

'git status'

問題なければ、以下を実行します。

`git add .`

`git commit -m "練習"` <- ここの ”” 部分には何をしたかわかる文章にしておくとわかりやすいです。

`git push origin feature/practice-自分の名前`

## 5. GitHubでPull Requestを作る
GitHubの画面を開いて「Pull Request」を作成し、自分で「Merge」ボタンを押して合流させます！

## 6. Merge したら main に戻る
Mergeが終わったら、次の作業に備えてmainを最新にする。

'git switch main'
'git pull origin main'

使い終わったブランチは削除してOKです。

'git branch -d feature/practice-自分の名前'
